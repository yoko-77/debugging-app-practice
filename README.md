# debugging-app-practice

## 概要

COACHTECH 教材 Tutorial 10-4「デバッグ ハンズオン演習」で作成した成果物です。
http://localhost/usersにて以下が可能なサイトを作成
・ユーザー登録
・登録済みユーザー一覧表示が可能

## 使用技術

- PHP 8.x
- Laravel 10.x
- デバッグツール（`dd()`, `dump()`, `Log` ファサード）、ブラウザ

## 学んだこと

- ブラウザのエラー表示内容を読む、対応する
- HTTPサイクルの登録

## 動作確認

http://localhost/usersにアクセスして、登録を実行
登録が完了したこと、登録した内容で一覧が表示されることを確認
